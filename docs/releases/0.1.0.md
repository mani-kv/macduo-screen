# MacFold 0.1.0 — macOS preview

First downloadable preview of MacFold, a native menu bar app that frosts and shades your MacBook's built-in display as you close the lid. Reopening reverses the effect.

## Download and install

1. Download `MacFold-0.1.0-macOS-arm64.zip` from this release and unzip it.
2. Move `MacFold.app` to Applications and open it.
3. This preview is ad-hoc signed and **not notarized**. If macOS blocks opening it, use System Settings → Privacy & Security → Open Anyway after attempting to open it, if you trust this download.
4. In MacFold Settings, choose **Allow Screen Recording…**, grant access, and relaunch if macOS requests it. Launch at login is optional.

Requires **macOS 14 or later**, **Apple Silicon**, and a MacBook exposing the Apple lid-angle HID sensor. Intel builds are not included. The app appears in the menu bar, with no Dock icon. Use **Preview…** to try the effect without sensor movement or Screen Recording permission.

The accompanying `.sha256` file can verify the archive from the download directory:

```sh
shasum -a 256 -c MacFold-0.1.0-macOS-arm64.zip.sha256
```

## Included

- Lid-driven blur, dimming, perspective, and stretch, with smooth entry at the threshold.
- Adjustable settings, launch at login, sample preview, and Test Desktop controls.
- One desktop snapshot per closing interaction; captured images are not saved.

## Preview limitations

The sensor interface is undocumented and hardware support varies. MacFold does not prevent normal lid-close sleep. The effect freezes desktop content during closing. Physical responsiveness, full close/sleep/wake, multiple Spaces, and external-display behavior still need manual validation. Ad-hoc updates may require refreshing Screen Recording permission.

## Validation

Release validation covers the Swift unit tests, optimized Apple Silicon build, bundled shader resources, strict code-signature verification, archive extraction, and offscreen Metal rendering checks. It does not establish physical-lid or fullscreen behavior.
