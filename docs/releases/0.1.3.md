# MacFold 0.1.3 — Desktop Spaces fix

Fixes the effect appearing only on the first desktop when using multiple macOS Spaces on the built-in display. The affected user confirmed that Test Desktop now works across desktops with no external monitor attached. Spaces support is automatic; no new setting is required.

## Changes

- The effect and Test Desktop use nonactivating floating panels so they can follow other apps across Spaces without activating MacFold's Settings window.
- The effect checks whether its window is on the active Space before deciding whether to bring it forward.
- Packaged apps find the shader in both newer and older Swift resource-bundle layouts.
- Source installs remove obsolete app-bundle files during upgrades, preventing stale resources from invalidating the code signature.

## Download and update

1. Download `MacFold-0.1.3-macOS-arm64.zip` and unzip it.
2. Quit MacFold, replace your copy in Applications, and open the updated app.
3. This preview is ad-hoc signed and **not notarized**. If macOS blocks it, use System Settings → Privacy & Security → Open Anyway after attempting to open it, if you trust this download.
4. If Screen Recording access stops working after the update, refresh MacFold's permission in System Settings and relaunch it.

Requires **macOS 14 or later**, **Apple Silicon**, and a MacBook exposing the Apple lid-angle HID sensor. Saved effect settings are retained. The app appears in the menu bar with no Dock icon.

Verify the downloaded archive with:

```sh
shasum -a 256 -c MacFold-0.1.3-macOS-arm64.zip.sha256
```

## Validation and limits

All 14 tests pass, including the native overlay panel regression check. That regression check fails with the old window behavior and passes with the fix. Release checks cover the optimized Apple Silicon build, strict signature verification, archive extraction and checksum, and the extracted app's offscreen Metal rendering checks.

The reported desktop Spaces issue is user-verified. Full close/sleep/wake, Stage Manager, rapid Space switching while reopening, and all full-screen Space configurations have not been exhaustively tested. The effect applies only to the built-in display, does not prevent normal lid-close sleep, and freezes desktop content while the snapshot effect is active.
