# MacFold 0.1.2 — Cross-app Spaces fix

Fixes a reported case where the effect appeared on only one desktop Space. The overlay and Test Desktop panel now explicitly opt into joining other applications, including their full-screen Spaces, in addition to joining all desktop Spaces. The user confirmed that the local patch resolved the reported issue.

## Download and update

1. Download `MacFold-0.1.2-macOS-arm64.zip` and unzip it.
2. Quit MacFold, replace your copy in Applications, and open the updated app.
3. This preview is ad-hoc signed and **not notarized**. If macOS blocks it, use System Settings → Privacy & Security → Open Anyway after attempting to open it, if you trust this download.
4. If Screen Recording access stops working after the update, refresh MacFold's permission in System Settings and relaunch it.

Requires **macOS 14 or later**, **Apple Silicon**, and a MacBook exposing the Apple lid-angle HID sensor. Saved effect settings are retained. The app appears in the menu bar with no Dock icon.

Verify the downloaded archive with:

```sh
shasum -a 256 -c MacFold-0.1.2-macOS-arm64.zip.sha256
```

## Validation and limits

Release checks cover all 13 unit tests, the optimized Apple Silicon build, strict signature verification, archive extraction/checksum, and the extracted app's offscreen Metal rendering checks.

The effect still applies only to the built-in display. Full close/sleep/wake, Stage Manager, and all full-screen Space configurations have not been exhaustively tested. The app does not prevent normal lid-close sleep, and desktop content freezes while the snapshot effect is active.
