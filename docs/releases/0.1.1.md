# MacFold 0.1.1 — Spaces fix

Fixes the effect disappearing when switching desktops/Spaces on the MacBook's built-in display. MacFold now captures the destination desktop and immediately reapplies the current lid or Test Desktop angle, without waiting for another input event. The overlay briefly hides while the new snapshot is prepared. Display-configuration changes use the same refresh path, and outdated captures are discarded.

## Download and update

1. Download `MacFold-0.1.1-macOS-arm64.zip` and unzip it.
2. Quit MacFold, replace your copy in Applications, and open the updated app.
3. This preview is ad-hoc signed and **not notarized**. If macOS blocks it, use System Settings → Privacy & Security → Open Anyway after attempting to open it, if you trust this download.
4. If Screen Recording access stops working after the update, refresh MacFold's permission in System Settings and relaunch it.

Requires **macOS 14 or later**, **Apple Silicon**, and a MacBook exposing the Apple lid-angle HID sensor. Saved effect settings are retained. The app appears in the menu bar with no Dock icon.

Verify the downloaded archive with:

```sh
shasum -a 256 -c MacFold-0.1.1-macOS-arm64.zip.sha256
```

## Validation and limits

The user confirmed the Spaces fix on their Mac. Release checks cover all 13 unit tests, the optimized Apple Silicon build, strict signature verification, archive extraction/checksum, and the extracted app's offscreen Metal rendering checks.

The effect still applies only to the built-in display. Full close/sleep/wake and all full-screen Space configurations have not been exhaustively tested. The app does not prevent normal lid-close sleep, and desktop content freezes while the snapshot effect is active.
